# Apex Lark – Day 08
## Advanced Data Cleaning & Data Transformation Using Pandas

### Project Overview
This project focuses on cleaning, transforming, and preparing a retail sales dataset using Python and Pandas. The objective was to identify data quality issues, create new business metrics, perform exploratory data analysis, and generate meaningful business insights.

### Objectives
- Perform data quality assessment.
- Clean and standardize dataset columns.
- Create new calculated columns using Pandas.
- Perform Exploratory Data Analysis (EDA).
- Visualize sales and profit trends.
- Generate actionable business recommendations.

### Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook
- GitHub

### Data Cleaning & Transformation
The following operations were performed:

- Checked missing values and duplicate records.
- Verified invalid values and text inconsistencies.
- Converted Order Date and Ship Date into datetime format.
- Removed unnecessary spaces from column names.
- Created new columns:
  - Unit Price
  - Total Sales
  - Profit Margin (%)
  - Discount Amount
  - Net Sales
  - Order Month
  - Order Year
  - Profit Category

### Exploratory Data Analysis
The following analyses were performed:

- Top 10 Products by Sales.
- Top 10 Customers by Revenue.
- Region-wise Sales.
- Category-wise Profit.
- Monthly Sales Trend.
- Average Order Value.

### Data Visualizations
Created visualizations using Matplotlib:

- Monthly Sales Trend – Line Chart.
- Sales by Region – Bar Chart.
- Profit by Category – Bar Chart.
- Top 10 Products by Sales – Horizontal Bar Chart.
- Distribution of Sales – Histogram.

### Key Business Insights
- **Highest Sales Region:** West.
- **Most Profitable Category:** Technology.
- **Monthly Trend:** Similar sales patterns were observed during the first six months across 2014, 2015, and 2016, with approximately 60–75% pattern similarity.

### Business Recommendations
1. Apply successful West region sales strategies to other regions.
2. Focus on high-performing Technology products.
3. Use monthly trends for sales forecasting.
4. Introduce targeted regional promotions.
5. Monitor product profitability regularly.

### Project Deliverables
- Python Notebook (.ipynb) or Python Script (.py).
- Cleaned Dataset (.csv).
- Business Analysis Report (.pdf).
- README.md.

### Conclusion
This project provided practical experience in data cleaning, transformation, exploratory data analysis, and visualization using Python. The analysis helped identify key sales and profitability patterns to support business decision-making.
